# Project Aegis

Project Aegis is a mod for Factorio. The goal is to create some kind of defensive structure or device. Exactly what this currently would be is unknown. It could take the form of:

Missile defense/intercept system
Physical barricade of some type
Container building like Factorissimo
Stealth device

This aims to potentially solve some of the problems on Castra with artillery, so whatever the solution is, needs to be able to passively handle long range attacks. Balance is not a big concern at the moment.
